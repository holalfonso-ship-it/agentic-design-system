# arc-cycles.json

Seed manual, no generado. Las cifras de hallazgos/cerrados de cada Ciclo
ARC viven en Notion ("🔁 Ciclos ARC — Aida"), no en este repo, así que no
hay forma de leerlas en un build estático de Storybook. Este archivo se
actualiza a mano después de cada Audit — añade una entrada nueva, no
edites las existentes salvo que el hallazgo original estuviera mal
contado.

report.json sí se genera (`npm run adoption-report`, no se edita a mano).
